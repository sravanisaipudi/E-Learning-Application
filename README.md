# 📚 E-Learning Web Application

## 📖 Overview
The E-Learning Web Application is a simple and responsive online learning platform developed using HTML, CSS, and JavaScript. The application allows users to explore available courses and enroll through an interactive user interface.

## 🚀 Features
- Responsive web design
- Course listing section
- Interactive "Enroll Now" button
- User-friendly interface
- Simple navigation menu
- Beginner-friendly project structure

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

## 📂 Project Structure

```text
E-Learning-Web-Application
│
├── index.html
├── style.css
└── script.js
```

## ▶️ How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in any web browser.
4. Browse available courses.
5. Click **Enroll Now** to interact with the application.

## 🎯 Project Objectives

- Develop a responsive learning platform.

- Implement interactive features using JavaScript.
